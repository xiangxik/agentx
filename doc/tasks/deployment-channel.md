# 渠道部署模块任务清单

## 目标

完成网站插件、独立聊天页和域名白名单的部署能力。

## 前端任务

- [x] 实现部署面板，展示插件脚本、chatbot 标识和独立聊天页链接。
- [x] 实现白名单域名管理页面：新增、删除、列表。
- [x] 实现一键复制部署代码与链接能力。
- [x] 实现最近部署访问情况展示区域。

## 后端任务

- [x] 定义部署配置结构与白名单域名存储方式。
- [x] 实现部署信息查询接口，返回插件脚本、chatbot 标识和独立聊天页链接。
- [x] 实现白名单域名新增、删除、列表接口。
- [x] 实现访客入口初始化校验接口。
- [x] 在初始化校验中同时校验 chatbot 状态、租户状态和域名白名单。
- [x] 为 `chatbot-widget` 提供标准初始化参数协议。
- [x] 为 `chat-page` 提供共享配置快照读取能力。
- [x] 记录最近部署访问情况所需的最小访问日志字段。

## 测试任务

- [x] 验证白名单域名生效。
- [x] 验证非白名单域名和非法 chatbot 标识被拦截。
- [x] 验证插件和独立聊天页共用同一配置快照。
