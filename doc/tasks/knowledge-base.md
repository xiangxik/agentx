# 知识库模块任务清单

## 目标

完成文件/网页知识导入、异步处理、向量入库和限定范围检索。

## 前端任务

- [ ] 实现知识来源列表页，区分文件来源与网页来源。
- [ ] 实现文件上传页，展示类型/大小限制和上传状态。
- [ ] 实现网页抓取配置页，支持 URL 录入、重抓、停用和失败提示。
- [ ] 实现知识来源详情页，展示解析状态、失败原因和来源信息。
- [ ] 实现异步任务状态轮询或刷新能力。

## 后端任务

- [ ] 定义 `KnowledgeSource`、`KnowledgeChunk`、任务状态和失败原因结构。
- [ ] 实现文件上传接口，校验文件类型、大小、租户归属和额度限制。
- [ ] 将原始文件保存到按租户隔离的本地目录，并记录文件元数据。
- [ ] 创建文件解析异步任务，支持状态查询、失败原因和重试次数记录。
- [ ] 实现文本解析、文本切分、向量生成、pgvector 入库流程。
- [ ] 实现网页来源创建接口，校验 URL 合法性、抓取频率和权限。
- [ ] 实现网页正文抓取、重抓和状态回写流程。
- [ ] 实现知识来源列表、详情、状态查询和失败重试接口。
- [ ] 实现检索服务接口，严格按 `tenant_id` 和 `chatbot_id` 限定候选片段。
- [ ] 在检索结果中返回片段摘要、来源标题、来源链接和相似度分数。

## 测试任务

- [ ] 验证各文件类型上传与解析。
- [ ] 验证文件失败重试与状态回写。
- [ ] 验证网页抓取成功、失败、重抓流程。
- [ ] 验证检索结果严格限定在当前租户和 chatbot 范围内。
- [ ] 验证回答引用来源可追溯到具体知识来源。
