# 对话编排模块任务清单

## 目标

完成匿名会话初始化、消息编排、FAQ/知识库/模型串联和待跟进记录闭环。

## 前端任务

- [ ] 在 `chatbot-widget` 和 `chat-page` 中实现会话初始化流程。
- [ ] 实现消息发送、消息列表、机器人输入中状态、错误提示和兜底话术展示。
- [ ] 实现知识引用来源展示。
- [ ] 实现回答有帮助/无帮助反馈入口。
- [ ] 实现转人工引导和待跟进信息提交表单。
- [ ] 为重复点击发送和网络异常提供前端保护。

## 后端任务

- [ ] 定义 `Conversation`、`Message`、`HandoffRecord` 及消息状态结构。
- [ ] 实现会话初始化接口，生成匿名访客 ID、会话 ID，并记录入口来源、浏览器信息、IP 和时间。
- [ ] 在消息处理前完成入口合法性、租户状态、chatbot 状态和额度状态校验。
- [ ] 实现访客消息写入逻辑。
- [ ] 对接 FAQ 匹配链路，命中时直接返回规则答案。
- [ ] 对接知识库检索链路，命中时携带引用上下文调用模型。
- [ ] 按行为策略实现“知识未命中时是否允许直接调用模型”的分支。
- [ ] 写入机器人回复、知识引用、模型调用日志关联信息。
- [ ] 实现统一错误兜底与兜底话术返回。
- [ ] 实现访客反馈提交接口。
- [ ] 实现待跟进信息提交接口，在机器人无法解决时保存问题和联系方式。
- [ ] 为重复提交消息补充幂等控制或重复影响最小化方案。

## 测试任务

- [ ] 验证匿名会话创建与多轮对话。
- [ ] 验证 FAQ 命中链路。
- [ ] 验证知识库命中链路。
- [ ] 验证知识未命中但允许大模型直答链路。
- [ ] 验证错误兜底、待跟进记录和访客反馈提交流程。
