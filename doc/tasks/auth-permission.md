# 认证与权限模块任务清单

## 目标

完成租户端与超级管理员端的后台认证、角色权限和安全控制闭环。

## 前端任务

- [x] 实现租户端登录页，支持邮箱密码输入、错误提示和提交态。
- [x] 实现超级管理员登录页，和租户端入口分离。
- [ ] 实现忘记密码页和重置密码页。
- [x] 实现登录后路由守卫，基于令牌与角色控制页面访问。
- [x] 实现退出登录入口与登录态清理。
- [ ] 实现成员管理页面：列表、创建、编辑、禁用、重置密码。
- [ ] 实现角色分配与权限矩阵查看页面。

## 后端任务

- [ ] 定义 `User`、`Role`、`Permission` 与登录失败计数相关数据结构，区分超级管理员与租户用户作用域。
- [ ] 实现邮箱密码登录接口，统一处理账户不存在与密码错误提示。
- [ ] 实现安全密码哈希存储与密码校验逻辑。
- [ ] 实现登录失败限频与锁定策略。
- [ ] 实现访问令牌签发、解析、退出登录能力。
- [ ] 实现忘记密码、重置密码接口与令牌校验流程。
- [ ] 实现基于角色/权限矩阵的接口鉴权中间层。
- [ ] 在认证上下文中统一注入 `user_id`、`tenant_id`、用户类型和角色集合。
- [ ] 实现成员管理接口：创建成员、编辑成员、禁用成员、重置密码。
- [ ] 实现角色列表、角色分配、权限矩阵查询接口。
- [ ] 接入审计日志：记录登录、退出、密码重置、成员管理等关键动作。

## 测试任务

- [ ] 验证正常登录、退出、忘记密码、重置密码流程。
- [ ] 验证错误密码限频与锁定提示。
- [ ] 验证禁用用户与禁用租户无法登录。
- [ ] 验证不同角色的页面与接口访问隔离。
- [ ] 验证超级管理员与租户后台用户作用域隔离。
