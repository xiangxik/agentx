# 二期工单模块任务清单

## 目标

为二期人工会话沉淀工单、状态流转和追踪分析提供独立模块。

## 前端任务

- [ ] 实现工单列表页、详情页。
- [ ] 实现从人工会话生成工单的操作入口。
- [ ] 实现负责人分配、状态流转和备注编辑界面。

## 后端任务

- [ ] 定义 `Ticket` 数据结构，包含负责人、状态、备注、处理结果和关联会话。
- [ ] 实现工单创建接口，从人工会话带出访客信息、问题摘要和上下文。
- [ ] 实现工单列表与详情接口。
- [ ] 实现工单状态流转接口。
- [ ] 加入“同一人工会话不可重复创建工单”校验。
- [ ] 加入“无负责人不得进入处理中状态”校验。
- [ ] 为统计模块提供工单关联查询字段。

## 测试任务

- [ ] 验证人工会话转工单流程。
- [ ] 验证工单状态流转。
- [ ] 验证工单与原会话追溯关系。
