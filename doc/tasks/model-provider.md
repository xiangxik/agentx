# 模型供应商与模型调用模块任务清单

## 目标

完成多供应商配置、统一模型调用适配、Token/成本记录和失败重试能力。

## 前端任务

- [ ] 实现超级管理员模型供应商管理页面。
- [ ] 实现模型列表、启停、默认模型设置页面。
- [ ] 实现租户端可用模型选择与展示区域。
- [ ] 实现模型调用失败率、Token 用量和成本概览展示。

## 后端任务

- [ ] 定义 `ModelProvider`、模型定义、`ModelCallLog` 和用途类型结构。
- [ ] 实现供应商配置管理接口。
- [ ] 实现模型启停、默认模型设置和租户可用模型查询接口。
- [ ] 对接安全配置，完成 API 密钥加密保存或安全读取。
- [ ] 实现统一模型调用服务，支持聊天回答和向量生成两种用途。
- [ ] 在调用前校验租户授权模型范围和 Token 额度。
- [ ] 实现超时控制、失败重试和失败明细记录。
- [ ] 写入 Token 用量、单价快照和成本估算。
- [ ] 对接对话编排模块和知识库向量生成流程。

## 测试任务

- [ ] 验证多供应商配置管理流程。
- [ ] 验证不同用途的模型调用日志完整性。
- [ ] 验证 Token 与成本统计正确性。
- [ ] 验证失败重试与失败率统计。
