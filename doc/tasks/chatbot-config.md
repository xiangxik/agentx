# Chatbot 配置模块任务清单

## 目标

完成 chatbot 基础信息、外观配置、行为策略和配置复制能力。

## 前端任务

- [ ] 实现 chatbot 列表页、详情页、创建页。
- [ ] 实现 chatbot 基础信息编辑页，支持名称、描述、语言、状态配置。
- [ ] 实现外观配置页，支持头像、欢迎语、主题色、按钮样式、品牌标识和中英文文案。
- [ ] 实现行为策略配置页，支持提示词、回复风格、兜底话术、敏感词策略、反馈开关、转人工开关和模型参数。
- [ ] 实现 chatbot 配置预览页，同时预览 widget 与 chat-page 效果。
- [ ] 实现启用、停用、删除、复制操作入口。

## 后端任务

- [ ] 定义 `Chatbot`、`ChatbotAppearance`、`ChatbotBehavior` 数据结构与状态枚举。
- [ ] 实现 chatbot 列表、详情、创建接口。
- [ ] 在创建 chatbot 时完成套餐数量校验。
- [ ] 为新 chatbot 自动生成默认外观配置与默认行为策略。
- [ ] 实现 chatbot 编辑、启用、停用、逻辑删除接口。
- [ ] 实现 chatbot 复制接口，仅复制配置，不复制会话和历史用量。
- [ ] 实现外观配置保存接口，覆盖名称、头像、欢迎语、主题色、按钮样式、品牌标识和多语言文案。
- [ ] 实现行为策略保存接口，覆盖提示词、回复风格、兜底话术、敏感词策略、知识引用开关、反馈开关、转人工开关和模型参数。
- [ ] 实现外观预览/配置快照接口，供 widget 与 chat-page 复用。

## 测试任务

- [ ] 验证创建、编辑、启停、复制 chatbot 流程。
- [ ] 验证停用后禁止新会话但允许查看历史记录。
- [ ] 验证外观和行为配置变更对两个入口同时生效。
