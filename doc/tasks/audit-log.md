# 审计日志模块任务清单

## 目标

完成关键操作留痕、风险级别标记和审计查询能力。

## 前端任务

- [ ] 实现超级管理员审计日志列表页。
- [ ] 实现按时间、用户、操作类型、租户的筛选能力。
- [ ] 实现审计详情页，展示资源、结果、风险级别和上下文。

## 后端任务

- [ ] 定义 `AuditLog` 数据结构，包含操作人、操作类型、目标资源、结果、时间、租户上下文和风险级别。
- [ ] 实现内部审计写入接口或统一写入服务。
- [ ] 为认证、租户、套餐、模型、数据导出、数据删除等关键模块接入审计事件。
- [ ] 为超级管理员跨租户访问单独标记高风险日志。
- [ ] 实现审计列表查询接口，支持按时间、用户、操作类型、租户过滤。
- [ ] 实现审计详情接口。
- [ ] 为审计写入失败增加告警或补偿入口。

## 测试任务

- [ ] 验证登录退出、套餐变更、模型配置、导出删除均有记录。
- [ ] 验证跨租户访问留痕。
- [ ] 验证普通租户无权查看平台审计日志。
