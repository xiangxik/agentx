# 租户管理模块任务清单

## 目标

完成超级管理员侧租户创建、状态管理和租户基础信息维护。

## 前端任务

- [ ] 实现超级管理员租户列表页，展示状态、联系人、备注和异常摘要。
- [ ] 实现租户创建页/弹窗，支持同时录入初始租户管理员信息。
- [ ] 实现租户编辑页/弹窗。
- [ ] 实现租户启用/禁用操作入口，并展示操作影响提示。
- [ ] 实现租户详情页，展示基础信息、管理员信息和用量摘要。

## 后端任务

- [ ] 定义 `Tenant` 实体与租户管理员初始化所需字段。
- [ ] 实现超级管理员创建租户接口。
- [ ] 在创建租户时自动创建初始租户管理员账号。
- [ ] 实现租户编辑接口，支持名称、联系人、备注、状态更新。
- [ ] 实现租户启用/禁用接口，并明确禁用后的行为约束。
- [ ] 实现租户列表、详情、异常概览接口。
- [ ] 为下游模块提供租户状态校验服务。
- [ ] 在关键状态变更时写入审计日志。

## 测试任务

- [ ] 验证创建租户与初始管理员流程。
- [ ] 验证禁用租户后的后台关键操作和新会话创建拦截。
- [ ] 验证超级管理员可以查看租户状态与基础摘要。
