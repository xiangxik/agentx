# 统计报表模块任务清单

## 目标

完成租户级工作台统计、平台级运营监控和二期统计预留。

## 前端任务

- [ ] 实现租户工作台首页，展示套餐信息、chatbot 数量、消息量、Token 用量、最近会话、未解决问题和通知位。
- [ ] 实现租户分析报表页面，展示会话数、消息数、活跃访客数、命中率、未解决率、转人工率、成本和额度消耗。
- [ ] 实现平台运营监控页面，展示平台级核心指标。
- [ ] 为图表增加时间范围选择与加载态。
- [ ] 为二期客服统计预留页面布局和字段位。

## 后端任务

- [ ] 定义租户级与平台级统计指标口径文档和返回结构。
- [ ] 实现租户工作台概览接口，输出套餐信息、chatbot 数量、消息量、Token 用量、最近会话、未解决问题和通知位。
- [ ] 实现租户分析报表接口，聚合会话数、消息数、活跃访客数、FAQ/知识命中率、未解决率、转人工率、成本与额度消耗。
- [ ] 实现平台运营监控接口，聚合租户总数、活跃租户、chatbot 总数、平台消息量、会话量、模型调用次数、Token 总量、成本、错误率和慢请求数。
- [ ] 为二期客服统计预留接口结构和字段位。
- [ ] 加入角色范围控制，区分租户级视图与超级管理员平台视图。
- [ ] 对大时间范围查询增加限窗、分页或预聚合策略。

## 测试任务

- [ ] 验证租户级与平台级指标隔离。
- [ ] 验证统计口径正确性。
- [ ] 验证大时间范围查询性能与可用性。
