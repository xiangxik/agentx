# 套餐额度与用量模块任务清单

## 目标

完成套餐定义、租户额度覆盖、资源超限校验和用量回写能力。

## 前端任务

- [ ] 实现超级管理员套餐管理页面：列表、创建、编辑、启停。
- [ ] 实现租户套餐分配与额度覆盖配置页面。
- [ ] 实现租户端额度与用量查看页面。
- [ ] 在 chatbot 创建、文件上传、消息发送等页面接入超限提示。

## 后端任务

- [ ] 定义 `Plan`、`TenantQuota`、`UsageRecord` 数据结构和资源类型枚举。
- [ ] 实现套餐创建、编辑、启停接口。
- [ ] 实现租户分配套餐接口。
- [ ] 实现租户级额度覆盖接口，不复制整套套餐定义。
- [ ] 实现额度查询接口，返回套餐值、覆盖值、当前已用值。
- [ ] 实现统一额度校验服务，支持机器人数量、消息量、文件数、容量、Token 五类资源。
- [ ] 实现用量回写能力，并标记消耗来源。
- [ ] 为 chatbot 创建、文件上传、消息发送、模型调用接入额度校验。
- [ ] 为用量回写失败补充补偿/告警入口。

## 测试任务

- [ ] 验证默认额度与覆盖额度叠加生效。
- [ ] 验证不同资源类型超限拦截与错误提示。
- [ ] 验证并发消耗场景下的数据一致性。
