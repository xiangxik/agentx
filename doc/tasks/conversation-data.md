# 会话记录与数据管理模块任务清单

## 目标

完成会话查询、详情聚合、脱敏展示、导出与删除治理能力。

## 前端任务

- [ ] 实现会话列表页，支持时间、chatbot、状态等筛选。
- [ ] 实现会话详情页，展示消息、FAQ 命中、知识引用、模型日志、反馈和待跟进信息。
- [ ] 实现会话已解决/未解决状态切换入口。
- [ ] 实现敏感信息脱敏展示和授权角色查看原始值入口。
- [ ] 实现会话导出与删除操作入口，并展示风险确认。

## 后端任务

- [ ] 定义会话列表、详情聚合和敏感字段脱敏规则。
- [ ] 实现会话列表接口，按当前租户和角色范围过滤。
- [ ] 实现会话详情接口，聚合消息、FAQ 命中、知识引用、模型日志、反馈与待跟进信息。
- [ ] 实现会话已解决/未解决状态更新接口。
- [ ] 实现敏感信息默认脱敏展示逻辑，并为授权角色开放原始值查看能力。
- [ ] 实现会话数据导出接口，限定在当前租户授权范围内。
- [ ] 实现会话数据删除接口，限定在当前租户范围内并采用软删/归档策略。
- [ ] 将导出与删除操作接入审计日志。

## 测试任务

- [ ] 验证列表与详情聚合完整性。
- [ ] 验证脱敏展示与授权查看原始值。
- [ ] 验证租户间导出/删除隔离。
- [ ] 验证导出与删除行为的审计留痕。
