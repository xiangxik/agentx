# 规则问答模块任务清单

## 目标

完成 FAQ 管理、导入导出和对话前置规则匹配能力。

## 前端任务

- [ ] 实现 FAQ 列表页，支持关键词搜索、语言筛选和状态筛选。
- [ ] 实现 FAQ 创建与编辑页。
- [ ] 实现 FAQ 启停、删除批量操作入口。
- [ ] 实现 FAQ 导入页，支持结果反馈和逐条失败提示。
- [ ] 实现 FAQ 导出入口。

## 后端任务

- [ ] 定义 `FAQ` 数据结构，包含主问题、相似问法、答案、语言、状态和 chatbot 归属。
- [ ] 实现 FAQ 列表、搜索、创建接口。
- [ ] 实现 FAQ 编辑、启停、逻辑删除接口。
- [ ] 实现 FAQ 批量导入接口，并返回逐条失败原因。
- [ ] 实现 FAQ 导出接口。
- [ ] 实现 FAQ 匹配服务接口，只匹配启用状态条目。
- [ ] 在匹配服务中加入语言维度过滤策略。
- [ ] 对接对话编排模块，确保 FAQ 命中后可直接返回规则答案。

## 测试任务

- [ ] 验证 FAQ CRUD、导入导出流程。
- [ ] 验证启用状态 FAQ 优先命中。
- [ ] 验证未命中时正确流转到知识库或模型流程。
