# 二期人工客服模块任务清单

## 目标

先完成 MVP 的转人工预留与待跟进记录，再为二期实时坐席能力留出清晰落点。

## 前端任务

- [ ] 在访客聊天界面实现转人工入口和联系方式表单。
- [ ] 实现租户端待跟进记录列表和详情页面。
- [ ] 预留坐席工作台入口、状态切换区和会话列表布局。
- [ ] 预留排队状态、实时消息区和会话处理结果录入区。

## 后端任务

- [ ] 定义 `HandoffRecord`、`AgentSession`、坐席状态和分配状态结构。
- [ ] 在 chatbot 对话侧暴露转人工入口开关与待跟进能力。
- [ ] 实现待跟进记录创建、列表、详情与状态更新接口。
- [ ] 在 MVP 范围内打通“机器人无法解决 → 留下问题和联系方式 → 生成待跟进记录”链路。
- [ ] 预留坐席在线/忙碌/离线状态接口结构。
- [ ] 预留排队、自动分配、手动分配接口结构。
- [ ] 预留实时消息通道协议和消息落库结构。
- [ ] 预留人工会话结束与处理结果记录结构。

## 测试任务

- [ ] 验证 MVP 待跟进记录链路。
- [ ] 验证二期接口契约和状态结构可扩展。
- [ ] 验证基础状态流转校验。
